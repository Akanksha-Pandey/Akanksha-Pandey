# Hi, I'm Akanksha

Computational biologist with a background in oncology drug discovery and evolutionary genomics. I build bioinformatics pipelines, apply machine learning to biological data, and care a lot about reproducible, well-documented science.

### What I work on

- **Cancer genomics & drug discovery** -- Multi-omics integration (RNA-seq, ChIP-seq, scRNA-seq), biomarker discovery, drug synergy analysis. Previously at Kronos Bio, where I worked across hematological malignancies, TNBC, SCLC, and HPV-driven cancers.
- **Statistical genetics** -- GWAS, association testing, population structure analysis. See [eopc-gwas](https://github.com/Akanksha-Pandey/eopc-gwas) for a recent example.
- **Proteomics** -- High-dimensional protein analysis (Olink Explore HT), pathway enrichment, longitudinal study design. See [ornish-proteomics](https://github.com/Akanksha-Pandey/ornish-proteomics).
- **Pipeline development** -- Nextflow/DSL2 workflows for NGS data, containerized with Docker, deployable on AWS and HPC.
